# ship-cloud-frontend

## Compose

For running compose you need to create `.env` file with following variables:

- `CLOUD_BACKEND_URL` - ship backend url
- `CMS_URL` - url to directus, uses as public url in directus service and api access url in frontend
- `CMS_ADMIN_EMAIL`
- `CMS_ADMIN_PASSWORD`
- `SECRET_KEY`
